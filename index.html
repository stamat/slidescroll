slidescroll

Archived. The 2024 successor to slidekick, superseded in 2026 by <carousel-elemental> from the Book of Elementals — same idea, keyboard and screen reader included. This slider has no keyboard support at all, which is why it was replaced. Use the elemental.

Installation

There is no npm package — this was never published. Clone the repo, or copy slidescroll.js and slidescroll.scss into your project. The source imports shallowMerge from book-of-spells.
